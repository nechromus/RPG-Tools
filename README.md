# RPG-Tools

Kleine, eigenständige Werkzeuge für Pen-&-Paper-Runden. Jedes Tool ist eine einzelne HTML-Datei: herunterladen, im Browser öffnen, fertig – funktioniert auch offline.

## Daggerheart SL-Begleiter

[`daggerheart-sl-begleiter/index.html`](daggerheart-sl-begleiter/index.html)

Begleit-App für Spielleitungen: Vorlesetexte, Entscheidungen, NSC und Gegner eines Abenteuers, dazu ein Kampf-Tracker für TP, Stress, Furcht, „War dran“, Effekt-Marker und Countdowns. Der Spielstand bleibt im Browser gespeichert.

Auf dem iPad: Seite in Safari öffnen → *Teilen* → *Zum Home-Bildschirm*. Die App läuft dann im Vollbild und offline und fragt selbst nach, wenn es eine neue Version gibt.

Abenteuer werden als `.json`-Datei geladen (Menü → „Abenteuer laden“). Diese Version enthält bewusst **keine** Abenteuertexte, da diese urheberrechtlich geschützt sind.
