# RPG-Tools

Kleine, eigenständige Werkzeuge für Pen-&-Paper-Runden. Jedes Tool ist eine einzelne HTML-Datei: herunterladen, im Browser öffnen, fertig – funktioniert auch offline.

## SL-Begleiter

[`daggerheart-sl-begleiter/index.html`](daggerheart-sl-begleiter/index.html)

Inoffizielle Begleit-App für Spielleitungen von Daggerheart™-Runden: Vorlesetexte, Entscheidungen, NSC und Gegner eines Abenteuers, dazu ein Kampf-Tracker für TP, Stress, Furcht, „War dran“, Effekt-Marker und Countdowns. Der Spielstand bleibt im Browser gespeichert.

Auf dem iPad: Seite in Safari öffnen → *Teilen* → *Zum Home-Bildschirm*. Die App läuft dann im Vollbild und offline und fragt selbst nach, wenn es eine neue Version gibt.

**Dieses Repo enthält nur Programmcode.** Abenteuer, Regeltexte, Kartentexte, Ausrüstungslisten und Gegnerwerte sind nicht enthalten; die App lädt sie zur Laufzeit aus einer privaten Ablage. Vor jeder Veröffentlichung prüft ein automatischer Schritt, dass keine solchen Inhalte im öffentlichen Paket stehen.
